## 2. 实体页通用骨架（跨簇不变式）

头部模板栈顺序惯例：

```wikitext
{{置顶导航}}                                  ← 546 页
[{{RichTab/信息框 | 变体1 | {{实体信息框/自动|dst|x|手写参数…}}
                | 变体2 | … }}]               ← 多变体聚合页 193 页；单实体则直接用实体信息框/自动
{{全角色台词|dst|X|首选=wurt}}                 ← 台词的标准挂载方式
'''中文名（{{en|English}}）'''是[[饥荒：联机版]]{{DST}}中的一种[[生物]]。
```

- **台词挂载惯例**：模板化（RichTab 区）1102 页 ＞ 双挂载 87 ＞ 仅章节 3 ＞ 无 493 ⇒ **台词不是章节，是头部模板**；
- **首句公式**：粗体名＋en 括注＋"是[[饥荒：联机版]]{{DST}}中的一种/一个…"，四主簇内标准形态 803/895 ≈ **90%**；偏离 92 页（有粗体无 en 66、无粗体 26）;
- **尾部章节惯例序**：正文主体 → 提示 → 花絮（→ 画廊 → 皮肤/皮肤套装 → 脚注）；h2 一律 `{{标题|X}}` 包装（3001 次 vs 裸标题长尾，见 §5）；
- `{{DST}}` 版本角标 1440/1685 页近乎必有。

## 3. 各簇特有结构

| 簇 | 特有章节（出现率） | 要点 |
|----|-------------------|------|
| **生物** n=145 | **行为 72%**、策略 28%、Bug 16%、其他信息 15% | 「行为」是生物页的核心手写区（仇恨/游荡/群体机制数值都在此）。内部 h3 惯例：战斗/攻击/群居/仇恨/进食；**Boss 用阶段式 h3**：`=== 第一阶段（16000 ~ 10000{{生命值}}） ===` |
| **食物** n=140 | **获取 51%**、料理烹饪 24% | "怎么得到"（采集/种植/交易/掉落）与"烹饪产物"两章为食物独有 |
| **物品** n=462 | 制作 25%、皮肤 27% | 结构最轻；合成相关常走 infobox 自动层 |
| **建筑** n=148 | 皮肤 39%、画廊 32% | 皮肤占比高于物品 |
| 机制页（游戏机制分类 80 页样本） | 台词→自定义世界→花絮→脚注 | **「自定义世界」是世界选项说明的惯用位置**；机制页也有台词章节（如"黑暗""饥饿值"的全角色描述） |

开头三连章节（top 序列）：生物 `行为→提示→花絮`；食物 `获取→提示→花絮`；物品/建筑多为 `花絮` 开头（即无正文章节的短页）。

## 4. 文字书写习惯（LLM 提示词素材）

| 习惯 | 形态 | 覆盖 |
|------|------|------|
| 数值区间 | `燃烧 6 ~ 12 秒`（波浪线两侧空格） | 215 页 |
| 时长 | `N 秒`／`N 分钟` | 416 页 |
| 距离/范围 | `100 距离单位` 或 `20 单位`，首次出现常配 `{{解释\|距离单位}}` | 解释模板 400 页 |
| 概率掉落 | `[[File:X.png|28px|link=Y]]×1（12.5%）`，多项 `<br>` 分隔 | ×N（P%）式 100 页 |
| 版本角标 | `{{DST}}`／`{{DS}}` 跟在"饥荒：联机版"链接后 | 1440 页 |
| 协作痕迹 | `{{待补充}}` 93 页、`{{未完成}}` 102 页、HTML 编辑备注 `<!-- … -->` **555 页**（如猎犬页 lulu 同步等待注释） | 生成器须决定保留/清除策略 |
| 图像覆盖 | 信息框手写 `图像N`/`图像N文字` 参数极常见（各簇 top10 全是它们） | 生物 56/145 页 |

**B 层覆盖参数实证**（F2 类事实的手写锚点确实存在）：生物页手写 `攻击范围`(14)、`伤害`(14)、`攻击间隔`(12)；物品页 `耐久`(12)——数量不大但正是会过期的手工数值点。

## 5. 不规范与待校准观察（非错误判定）

1. **消歧义标记与实体内容并存**：如「触手」页同时含 `{{消歧义}}` 和完整实体信息框+正文。当前分类器 S1(消歧义)>S2(模板) 把 223 页全归 disambig，其中此类"真实体页"应改按信息框归类、页内标注歧义区——**列入分类器校准首批项**；
2. **裸 h2 标题长尾**：`获取`(88)、`脚注`(85)、`区块构成`(68)、`生成`(19) 等未走 `{{标题}}` 包装，多来自 RichTab 子页或旧版格式——segmenter 需兼容两种形态；
3. 首句公式 ~8% 偏离（多为老页或角色类复杂介绍）；
4. `Bug` 章节时效性最强（游戏修复后即过期），未来更新扫描时值得单独跟踪；
5. unknown 分类残余 128 页以版本中立页为主（首页/版本历史/机制总览），符合预期。

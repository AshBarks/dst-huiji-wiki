## 2. 实体页通用骨架（跨簇不变式）

头部模板栈顺序惯例：

```wikitext
{{置顶导航}}                                  ← 546 页
[{{RichTab/信息框 | 变体1 | {{实体信息框/自动|dst|x|手写参数…}}
                | 变体2 | … }}]               ← 多变体聚合页 193 页；单实体则直接用实体信息框/自动
{{全角色台词|dst|X|首选=wurt}}                 ← 台词的标准挂载方式
'''中文名（{{en|English}}）'''是[[饥荒：联机版]]{{DST}}中的一种[[生物]]。
```

- **台词挂载惯例**：模板化（RichTab 区）1102 页 ＞ 双挂载 87 ＞ 仅章节 3 ＞ 无 493 ⇒ **台词不是章节，是头部模板**；
- **首句公式**：粗体名＋en 括注＋"是[[饥荒：联机版]]{{DST}}中的一种/一个…"，四主簇内标准形态 803/895 ≈ **90%**；偏离 92 页（有粗体无 en 66、无粗体 26）;
- **尾部章节惯例序**：正文主体 → 提示 → 花絮（→ 画廊 → 皮肤/皮肤套装 → 脚注）；h2 一律 `{{标题|X}}` 包装（3001 次 vs 裸标题长尾，见 §5）；
- `{{DST}}` 版本角标 1440/1685 页近乎必有。

## 5. 不规范与待校准观察（非错误判定）

1. **消歧义标记与实体内容并存**：如「触手」页同时含 `{{消歧义}}` 和完整实体信息框+正文。当前分类器 S1(消歧义)>S2(模板) 把 223 页全归 disambig，其中此类"真实体页"应改按信息框归类、页内标注歧义区——**列入分类器校准首批项**；
2. **裸 h2 标题长尾**：`获取`(88)、`脚注`(85)、`区块构成`(68)、`生成`(19) 等未走 `{{标题}}` 包装，多来自 RichTab 子页或旧版格式——segmenter 需兼容两种形态；
3. 首句公式 ~8% 偏离（多为老页或角色类复杂介绍）；
4. `Bug` 章节时效性最强（游戏修复后即过期），未来更新扫描时值得单独跟踪；
5. unknown 分类残余 128 页以版本中立页为主（首页/版本历史/机制总览），符合预期。

## 7. 章节内容范围与 LLM 介入边界（v2 增补，2026-08-26 讨论）

介入边界的权威表在 [UPDATE_IMPACT_PLAN.md](UPDATE_IMPACT_PLAN.md) §4.2.4（v3.2）；本节记录语料侧实证与溯源事实。

### 7.1 无标题导语区＝页面主体

模板栈之后到首个 h2 之前没有章节名，但它是**页面的主体**：身份公式句 + 核心机制概述段（死亡效果/特殊互动/生成条件），B 层事实密度全页最高，且是读者第一眼、更新最易显旧的位置。可含变体子章节（`===火焰猎犬===` 式）。边界要点：

- 数值/字面量句 → draft（old_literal 命中）；
- 无字面量的单跳事实句（"死去的猎犬会留下尸体并冒出恐怖猎犬"）→ 先 flag；关联索引的 SpawnPrefab 类边就绪后再评估升格——这类句子正是未来 CodeTextAtlas 的首批锚点；
- 身份公式句仅重命名事件驱动。

### 7.2 溯源事实记录（供未来提取器）

| 事实 | 出处 |
|------|------|
| **料理配方 ≠ 制作配方**：制作配方在 recipes.lua，精确材料表（`Ingredient("dragonfruit",1)`），确定性强；料理配方在 preparedfoods.lua 等，是**规则约束**（foodtype/priority/cooktime，实测字段确认），不强制具体材料 | 故料理页「获取」章 = 散文规则摘要 + `{{烹饪}}` 示例枚举，示例非唯一真值，校对时不得当完整清单 |
| **制作章新增可纯代码检验**：实体首次成为 recipes.lua 任一配方的 Ingredient ⇒ 页面应出现制作章/RRBI 引用；缺失进 create-check 类报告 | 版本更新后的新增制作材料的常见遗漏点 |
| 自定义世界数值定义于 worldsettings_overrides.lua（3845 行，皮弗娄牛发情参数等与页面表格值一一对应），但机制解释可能跨多文件 | 代码追溯索引的后续工作项 |
| 提示 = 代码事实 + 玩家需求的推论；策略 = 纯主观经验；二者有代码依赖但无追溯价值 | 只 flag 不代改 |
| 行为章是主要介入区，也是复杂度最高、最需要取舍判断的章节 | MVP 标定样本应以此为主 |

### 7.3 边界速查（四档制）

draft：导语数值句 / 信息框手写参数 / 行为数值句 · flag：导语单跳事实句 / 获取·料理烹饪 / 自定义世界 / 提示 / 策略 · ignore：花絮(重命名监听可选) / 皮肤 / Bug / 画廊 · Tier0-only：信息框自动层 / 台词模板 / 制作模板。横切规则见主方案 §4.2.4。
